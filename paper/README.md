# paper/: the ARS academic-pipeline workspace

This folder holds the deliverables of the
[academic-research-skills](https://github.com/Imbad0202/academic-research-skills) `academic-pipeline`
(ARS v3.24.x), one folder per stage. Experiments and the lab record stay in `experiments/` and
`research/`. The pipeline reads from those folders and writes here.

| ARS stage | Folder | Deliverables (ARS version label) | Fed by |
|---|---|---|---|
| 1 RESEARCH (`deep-research`) | [stage1_research/](stage1_research/) | RQ Brief, Methodology Blueprint, Bibliography, Synthesis (`research_vN`) | `research/overview.md`, `research/related_work.md`, literature corpus |
| 2 WRITE (`academic-paper`) | [stage2_draft/](stage2_draft/) | Paper draft (`paper_draft_vN`) | Stage 1 + experiment provenance + `figures/` |
| 2.5 INTEGRITY | [stage2.5_integrity/](stage2.5_integrity/) | Integrity report (`integrity_mid_vN`) | Draft + passport |
| 3 REVIEW (`academic-paper-reviewer`) | [stage3_review/](stage3_review/) | 5 review reports, editorial decision, revision roadmap (`review_vN`, `roadmap_vN`) | Verified draft |
| 4 REVISE / 4' RE-REVISE | [stage4_revision/](stage4_revision/) | Revised draft, Response to Reviewers (`revision_vN`) | Roadmap |
| 3' RE-REVIEW | [stage3_review/](stage3_review/) | Verification review (`review_v2`, `roadmap_v2`) | Revision bundle |
| 4.5 FINAL INTEGRITY | [stage4.5_final_integrity/](stage4.5_final_integrity/) | Final integrity report (`integrity_final_vN`) | Final draft |
| 5 FINALIZE | [stage5_final/](stage5_final/) | MD, and on request .tex/PDF (via LaTeX) and DOCX | Accepted draft |
| 6 PROCESS SUMMARY | [stage6_process_record/](stage6_process_record/) | Paper creation process record | Pipeline history |
| (shared) | [passports/](passports/) | Material Passport + run ledger | Every stage |
| (shared) | [figures/](figures/) | Paper figures, each generated by a script from a run directory | `experiments/E###/results/` |

## Conventions

- **Never overwrite.** ARS versions are monotonic. Save each new version as a new file
  (`paper_draft_v2.md`), and never edit `paper_draft_v1.md` in place.
- **Passport path.** The pipeline looks for `./passports/` relative to the working directory. Claude
  runs from the repo root, so always give the path explicitly: `paper/passports/cuekeep_passport.yaml`.
  The run ledger lives beside it and is written only by ARS's `scripts/run_ledger.py`. Never edit the
  ledger by hand.
- **Experiments are external to ARS.** ARS does not run or judge experiments. After Stage 1, the
  orchestrator asks whether the paper reports experiments. Answer yes, then supply the
  `experiment_provenance[]` block generated by `python scripts/export_provenance.py` (see below).
  Every empirical claim in the draft must cite an `experiment_id` (`E001`, ...).
- **Literature corpus.** Reading notes in `research/literature/papers/` use the ARS Obsidian adapter's
  Convention A frontmatter. Build `literature_corpus[]` with `bash scripts/build_corpus.sh`.
- **Numbers come from runs.** Every number in a draft must trace to `experiments/E###/results/` and
  from there to a `runs/` directory. Stage 2.5/4.5 checks this against the provenance.

## Typical session

```text
/academic-research-skills:academic-pipeline
> I want to write the CueKeep paper. Passport: paper/passports/cuekeep_passport.yaml.
> Research context: research/overview.md, research/method.md, research/related_work.md.
```

Before Stage 2, make sure the experiments that the claims need are marked ✓ or ✗ (not ☐) in
`experiments/README.md`, and that their `provenance.yaml` is complete.
